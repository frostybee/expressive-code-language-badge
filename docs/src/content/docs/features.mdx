The Language Badge plugin enhances your code blocks by adding visual language indicators.

:::note
Once installed, the plugin **automatically** adds language badges to your Expressive Code blocks:

- Badges appear in the top-right corner of code blocks.
- They fade out on hover for better code visibility.
- Fully customizable styling and behavior.
:::

## How it works

- Automatically detects and displays the language for all code blocks.
- Badges adjust position for titled and terminal-styled blocks.
- Custom language mappings for special cases (e.g., `cpp` → `C++`).
- Exclude specific languages from showing badges.

## Features

- **Automatic language detection:**  Shows the programming language for each code block.
- **Custom language labels:** Remap language identifiers to custom display names.
- **Exclude languages:** Hide badges for specific languages like JSON or CSS.
- **Text transform:** Choose uppercase or lowercase display.
- **Hover interaction:** Badges fade out on hover for unobstructed code viewing.
- **Fully customizable:** Extensive styling options for colors, fonts, borders, and more.
- **Responsive positioning:** Automatically adjusts for titled and terminal blocks.
